# StudyBuddy full visual refresh

This update refreshes the visual system across the landing page and workspace routes while retaining the existing page features and data logic.

## Changes
- Replaced the dominant neon/glow look with a calmer midnight workspace palette, mint accent, subtle borders, clearer type hierarchy, and quieter card surfaces.
- Refreshed shared sidebar/navigation, input focus styles, panels, landing hero typography, section spacing, and responsive behavior.
- Added mobile-safe grid and padding rules plus reduced-motion support.
- Removed an old ZIP archive that had been accidentally bundled inside the project source.

## Verification limits
- Source ZIP structure and local imports were checked previously.
- A production build, browser visual test, and interaction test still need to be run in an environment with project dependencies installed. This package should not be described as fully verified until those checks pass.
